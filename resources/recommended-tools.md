# Recommended Developer Tools & Services 🛠️

A curated list of battle-tested, developer-first tools, libraries, and cloud services for building modern, production-grade applications.

---

## ☁️ Hosting & Cloud Platforms

| Platform | Best For | Highlights |
| :--- | :--- | :--- |
| **[Vercel](https://vercel.com/)** | Frontend & Serverless Next.js/Nuxt | Preview URLs, Edge Functions, zero-config CI/CD |
| **[Render](https://render.com/)** | Full-stack apps, Web services & Background workers | Native Docker deploys, managed Postgres/Redis, fast setup |
| **[Fly.io](https://fly.io/)** | Global multi-region container deployments | Low-latency edge containers, Anycast IPs |
| **[Coolify](https://coolify.io/)** | Self-hosted PaaS alternative to Heroku | Host on your own VPS with automated SSL and Git deploys |
| **[Hetzner](https://www.hetzner.com/)** | High-performance, low-cost bare metal & VPS | Unbeatable price-to-performance ratio for servers |

---

## 🗄️ Managed Databases & Storage

- **[Neon](https://neon.tech/)**: Serverless Postgres with instant branching and autoscaling.
- **[Supabase](https://supabase.com/)**: Open-source Firebase alternative with Postgres, Auth, Realtime, and Storage.
- **[Upstash](https://upstash.com/)**: Serverless Redis & Kafka with per-request pricing and REST API.
- **[Cloudflare R2](https://www.cloudflare.com/products/r2/)**: S3-compatible object storage with **zero egress fees**.

---

## 🔒 Authentication & Security

- **[Clerk](https://clerk.com/)**: Complete user management, MFA, and prebuilt React/Next.js components.
- **[Auth0](https://auth0.com/)**: Enterprise-grade identity provider with SAML/SSO support.
- **[Lucia Auth](https://lucia-auth.com/)**: Simple, flexible self-hosted authentication library for TypeScript.
- **[Trivy](https://github.com/aquasecurity/trivy)**: Comprehensive vulnerability scanner for container images.

---

## 📊 Monitoring, Observability & Analytics

- **[Sentry](https://sentry.io/)**: Gold standard for real-time application crash reporting and distributed tracing.
- **[Better Stack](https://betterstack.com/)**: Fast log management and uptime status monitoring with beautiful UI.
- **[PostHog](https://posthog.com/)**: All-in-one product analytics, session replay, feature flags, and A/B testing.
- **[Plausible Analytics](https://plausible.io/)**: Lightweight, cookie-free, privacy-first web analytics.

---

## ✉️ Communications & Background Jobs

- **[Resend](https://resend.com/)**: Modern email API built for developers using React Email templates.
- **[Postmark](https://postmarkapp.com/)**: Best-in-class transactional email deliverability and speed.
- **[Inngest](https://www.inngest.com/)**: Event-driven background jobs, workflows, and step functions without managing queues.
- **[BullMQ](https://bullmq.io/)**: High-performance Redis-based job and message queue for Node.js.
