# Recommended Books & Courses 📖🎓

Essential literature and learning resources to elevate your software engineering, system design, and architecture skills from intermediate to senior/principal level.

---

## 📚 Essential Engineering Books

### 1. System Design & Distributed Systems
- **[Designing Data-Intensive Applications](https://dataintensive.net/)** by *Martin Kleppmann*
  - *The definitive bible for understanding storage engines, replication, partitioning, transactions, and distributed consensus.*
- **[System Design Interview – An Insider's Guide (Vol 1 & 2)](https://bytebytego.com/)** by *Alex Xu*
  - *Practical architectural blueprints for scaling chat systems, rate limiters, search engines, and CDNs.*
- **[Building Microservices (2nd Edition)](https://www.oreilly.com/library/view/building-microservices-2nd/9781492034018/)** by *Sam Newman*
  - *Deep dive into service boundaries, migration patterns, and distributed workflows.*

### 2. Software Craftsmanship & Clean Architecture
- **[A Philosophy of Software Design](https://web.stanford.edu/~ouster/cgi-bin/book.php)** by *John Ousterhout*
  - *Brilliant alternative perspective on complexity, deep modules, and cognitive load management in codebases.*
- **[Refactoring: Improving the Design of Existing Code](https://martinfowler.com/books/refactoring.html)** by *Martin Fowler*
  - *Techniques for safely transforming messy legacy code into clean, testable architectures.*

### 3. Reliability & Site Reliability Engineering (SRE)
- **[Site Reliability Engineering](https://sre.google/sre-book/table-of-contents/)** by *Betsy Beyer, Chris Jones, Jennifer Petoff, Niall Richard Murphy (Google SRE Team)*
  - *Free online resource explaining error budgets, SLI/SLOs, monitoring, and post-mortem cultures.*

## 🎓 High-Impact Courses & Platforms

- **[ByteByteGo System Design by Alex Xu](https://bytebytego.com/)**: Interactive visual lessons on modern high-scale system design.
- **[Frontend Masters](https://frontendmasters.com/)**: Deep-dive advanced courses on TypeScript, React internals, Node.js performance, and Web Security.
- **[Total TypeScript by Matt Pocock](https://www.totaltypescript.com/)**: World-class workshops on mastering advanced TypeScript generics and patterns.
- **[Execute Program](https://www.executeprogram.com/)**: Spaced-repetition interactive programming courses on TypeScript, SQL, Concurrency, and Regex.
